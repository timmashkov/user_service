# user_service


## Описание

<details>
<summary><b>Информация:</b></summary>

1. Микросервис для работы с юзером

    Технологии:
     - FastAPI
     - SQLAlchemy
     - Alembic
     - Redis
     - RabbitMQ

    Реализовано:
      - CRUD операции с сущностями: user, role, permission
      - У каждого юзера есть свои роли, у каждой роли есть свои разрешения
      - Авторизация(логин, логаут, проверка авторизации, обновление токенов)
